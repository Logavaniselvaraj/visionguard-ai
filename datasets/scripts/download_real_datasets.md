# Real datasets (download manually — large, licence terms apply)

| Dataset | Use in VisionGuard | Where |
|---|---|---|
| UA-DETRAC | vehicle detection + tracking (traffic CCTV) | detrac-db.rit.albany.edu |
| MOT17 / MOT20 | multi-object tracking benchmark | motchallenge.net |
| AI City Challenge (CityFlow) | cross-camera vehicle re-ID | aicitychallenge.org |
| VIRAT | surveillance activities (entering vehicles, carrying) | viratdata.org |
| UCF-Crime | anomaly / alert testing | crcv.ucf.edu/projects/real-world |
| COCO | pretrained YOLO classes (person, car, backpack…) | cocodataset.org |

Check each site for the current download page and licence before use.
